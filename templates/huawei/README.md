# Huawei templates

Zabbix 7.0.30 stock seed data supplies the official `Huawei VRP by SNMP`
template, which is verified after installation. The repository does not fork
that template.

`../huawei_ar8100_extensions_by_snmp.yaml` is an intentionally empty,
non-production scaffold. It contains no active OIDs or monitoring entities and
must not be linked until device evidence proves an AR8100-specific extension.
