# Network Utilization v1.0 LAB validation

Date: 2026-09-27

## Result

Network Utilization 1.0.0 passed authenticated LAB validation on Zabbix 7.0.30, PHP 8.3.19 and RHEL 9.6. Production was not accessed. Network Availability source and deployment files were not changed.

## Real data inspected

- Five monitored Hosts and 261 enabled Items were retrieved in bulk.
- The only live interface candidate was `ZABBIX-01 / ens18`.
- IN source: `net.if.in["ens18"]`, native Zabbix `bps`, change-per-second then multiply by 8, three-minute interval.
- OUT source: `net.if.out["ens18"]`, native Zabbix `bps`, change-per-second then multiply by 8, three-minute interval.
- Error/discard sources: native IN/OUT error and drop rate Items; all observed values were zero.
- Operational state source: `net.if.status["ens18",operstate]`; observed UP. No admin-state Item was available, so admin state remained UNKNOWN.
- Reported speed was unsupported for this virtual NIC. The widget correctly displayed current traffic while capacity, utilization and headroom remained UNKNOWN.

FortiGate, F5 BIG-IP and Nexus interface prototypes were inspected offline and recognized by the collector. The four LAB network Hosts are intentional mock objects with fake, unreachable addresses and expose no live discovered interface Items. No vendor polling claim is made.

## Analytics comparison

For a temporary LAB-only Link definition, an explicit 1 Gbps capacity override was applied after the unknown-capacity behavior passed. A fresh authenticated render reported:

- Current IN: 10,200 bps / 0.00102%
- Current OUT: 4,144 bps / 0.0004144%
- P95 IN 24H: 0.00967328%
- P95 OUT 24H: 0.0007508%
- Data state: CURRENT; data age: 15 seconds
- History rows: 471; trend rows: 24

Current percentages matched the native Item values divided by the explicit capacity. P95 IN and OUT were independently recalculated from the same bounded native history and matched the widget. The explicit override was removed and the external runtime store was restored to an empty production-neutral configuration at revision 12.
